# Android App

Native Android client for the ah-he platform, built with Kotlin and Jetpack Compose.

## Tech Stack
- Kotlin
- Jetpack Compose
- Kotlin Multiplatform (shared module)

## Building

```bash
./gradlew :androidApp:assembleDebug
```

## Project Structure
```
androidApp/
├── src/main/
│   ├── kotlin/com/ahhe/android/   # App code
│   └── res/                        # Resources
└── build.gradle.kts
```
