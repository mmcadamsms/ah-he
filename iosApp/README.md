# iOS App

Native iOS client for the ah-he platform, built with Swift and SwiftUI.

## Tech Stack
- Swift
- SwiftUI
- Kotlin Multiplatform (shared module via framework)

## Building

Open `iosApp/iosApp.xcodeproj` in Xcode (macOS required).

## Project Structure
```
iosApp/
├── iosApp/
│   ├── ContentView.swift
│   ├── iOSApp.swift
│   └── Info.plist
└── iosApp.xcodeproj
```
