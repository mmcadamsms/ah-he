# Architecture Overview

This directory contains detailed architecture documentation for the ah-he platform.

## Contents

- [overview.md](overview.md) — Detailed component architecture
- [decisions/](decisions/) — Architecture Decision Records (ADRs)

## Adding an ADR

Copy the template in `decisions/` and number sequentially:

```
decisions/0002-my-decision.md
```

See [ADR 0001](decisions/0001-record-architecture-decisions.md) for the format.
