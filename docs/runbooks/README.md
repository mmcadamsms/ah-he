# Operational Runbooks

This directory contains runbooks for operating the ah-he platform.

## Structure

Each runbook should cover:
1. **When to use** — what symptom or scenario triggers this runbook
2. **Prerequisites** — access, tools, permissions needed
3. **Steps** — numbered, actionable steps
4. **Rollback** — how to undo if something goes wrong
5. **Escalation** — who to contact if the runbook doesn't resolve the issue
