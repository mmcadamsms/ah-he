# Discovery Question Inbox

## Purpose

Use this file only when a new question does not yet have an obvious canonical
topic. Questions should be triaged into a file under `topics/` and assigned a
permanent ID promptly.

Do not maintain a second copy here after moving a question. Replace the inbox
entry with a link to its canonical ID if preserving the intake history is
useful.
