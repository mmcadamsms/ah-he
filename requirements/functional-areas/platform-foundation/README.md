# Platform Foundation

## Scope

Shared durability, evidence, asynchronous work, identity/access boundaries,
diagnostics and recovery across business domains. This area defines common
capabilities, not a new deployable service or replacement domain requirements.

## Requirements

- [Unified Operations Storage and Logging](unified-operations-storage-and-logging.md)
  - Azure-first portable cloud platform for backlog items 1-5; proposed design,
    implementation gated on user agreement.
- [Actor and Beneficiary Operation Context](actor-and-beneficiary-operation-context.md)
  - Shared actor/representation/authority, beneficiary/purpose and subject
    contracts for customer, employee, device and service operations.
